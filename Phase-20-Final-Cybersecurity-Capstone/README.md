# Phase 20: Final Cybersecurity Capstone

## Objective
Summarize the skills developed across the home cybersecurity lab and demonstrate a repeatable process for investigating network and system behavior.

## Lab Environment
- Apple M1 Mac host
- Ubuntu and Windows virtual machines
- Tools explored: Linux and Windows networking commands, Nmap, and Wireshark
- OWASP Juice Shop planned for controlled web-security practice

## Skills and Topics Reviewed
- Linux and Windows fundamentals
- IP addressing, routing, DNS, and connectivity troubleshooting
- Network scanning and port states
- Packet capture and protocol analysis
- Security fundamentals and system hardening
- Vulnerability assessment methodology
- Web application security concepts
- SOC monitoring and incident-response workflows
- Evidence handling and technical documentation

## Capstone Workflow
1. Confirm the asset and authorization.
2. Record the system and network configuration.
3. Test basic connectivity.
4. Run only in-scope discovery or service checks.
5. Capture traffic when useful and select the correct interface.
6. Review evidence and distinguish facts from assumptions.
7. Recommend a proportionate defensive improvement.
8. Document limitations and verify any changes.

## Analysis and Findings
- The project connected Linux and Windows networking concepts with practical tools for discovery and packet analysis.
- Setup troubleshooting highlighted the importance of checking interface selection, IP addressing, routing, and target reachability.
- Nmap results must be interpreted carefully: a filtered port does not establish that a service is open or closed, and a service detection result alone does not prove a vulnerability.
- Wireshark analysis depends on capturing the correct interface and generating relevant traffic.

## Lessons Learned
- Troubleshooting is easier when each step is tested and documented.
- Tools produce evidence, but analysts must interpret it in context.
- Security findings should include evidence, impact, limitations, and remediation.
- Authorized scope and privacy protection are essential throughout security work.
