# Phase 16 — Active Directory & Windows Security

## Objective
Learn foundational Windows security and Active Directory concepts relevant to managing identities and permissions in organizational environments.

## Topics Covered
- Local versus domain accounts
- Authentication and authorization
- Groups and permissions
- Least privilege
- Windows security logs
- Domain controllers and directory services

## Activities
- Review Windows account and group concepts.
- Distinguish local authentication from domain authentication.
- Explore Windows Event Viewer and security-related logs where available.
- Document how group membership and permissions affect access.
- Treat Active Directory-specific activities as conceptual unless a domain lab has actually been configured.

## Analysis and Findings
- A Windows VM provides a starting point for learning endpoint configuration and security concepts.
- Active Directory requires a configured domain environment;
- Least privilege and appropriate monitoring are central controls for Windows environments.

## What I Learned
Windows security involves identity, permissions, system configuration, and event visibility. Active Directory adds centralized identity and policy management in domain environments.

## Cybersecurity Relevance
These concepts are useful for service desk support, endpoint security, SOC investigations, and enterprise identity protection.
