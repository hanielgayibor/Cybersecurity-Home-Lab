# Phase 1 — Linux & Virtualization Fundamentals

## Objective

The goal of this phase was to establish the foundation for my cybersecurity home lab. I began learning about Linux, virtual machines, operating systems, and how to create an environment for practicing cybersecurity skills.

## Lab Environment

* **Host computer:** Apple Mac with M1 chip
* **Linux virtual machine:** Ubuntu
* **Windows virtual machine:** Used in later lab exercises
* **Virtualization:** Virtual machines running in an isolated lab environment

## Topics Covered

* Introduction to Linux
* Understanding virtual machines
* Operating system fundamentals
* Linux terminal basics
* Navigating files and directories
* Identifying system information
* Understanding IP addresses and network interfaces
* Preparing a lab environment for future security exercises

## Commands Practiced

The following Linux commands are useful for understanding and inspecting a Linux system.

| Command    | Purpose                                      |
| ---------- | -------------------------------------------- |
| `whoami`   | Displays the current username                |
| `hostname` | Displays the computer's hostname             |
| `pwd`      | Displays the current directory               |
| `ls`       | Lists files and directories                  |
| `cd`       | Changes the current directory                |
| `uname -a` | Displays system and kernel information       |
| `ip addr`  | Displays network interfaces and IP addresses |

## What I Learned

This phase introduced me to the Linux command line and the role virtual machines play in building a cybersecurity lab. I learned that virtual machines allow different operating systems to run in an environment where I can practice system administration and security concepts.

These fundamentals prepared me for later phases involving networking, Nmap, Wireshark, vulnerability assessment, and system hardening.

## Security Relevance

Linux knowledge is important in cybersecurity because analysts frequently use Linux systems to inspect network configurations, investigate logs, manage permissions, and run security tools.

Virtualization also provides a way to practice security techniques in a controlled environment without intentionally testing systems outside the lab.

## Next Steps

The next phase focuses on networking fundamentals, including IP addresses, communication between devices, and the basics of TCP/IP.
