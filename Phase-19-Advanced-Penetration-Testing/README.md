# Phase 19 — Advanced Penetration Testing

## Objective
Bring together reconnaissance, service review, web security concepts, and reporting into a more complete assessment workflow within an authorized lab.

## Topics Covered
- Scope confirmation
- Reconnaissance and enumeration
- Evidence-based validation
- Risk assessment
- Remediation planning
- Retesting and reporting

## Activities
- Reconfirm the lab target and permitted actions.
- Review prior scan and packet-analysis notes.
- Identify one area for additional investigation based on actual evidence.
- Record the observation, its limitations, and a defensive recommendation.
- Retest only after an authorized configuration change.

## Analysis and Findings
- Earlier phases introduced Nmap scanning, interpreting filtered ports, and using Wireshark for packet analysis.
- These tools provide different perspectives: Nmap probes exposed services, while Wireshark captures traffic visible on a selected interface.

## What I Learned
A more complete assessment combines multiple sources of evidence and links each finding to a realistic risk and remediation step.

## Cybersecurity Relevance
The workflow supports vulnerability assessment and penetration-testing work while reinforcing safe scope management and responsible reporting.
